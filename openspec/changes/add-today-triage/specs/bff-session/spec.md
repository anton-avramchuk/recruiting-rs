## ADDED Requirements

### Requirement: Сводка и интервью в клиентском BFF
Клиентский BFF SHALL проксировать в сервис воронки маршруты сводки и интервью (`/overview`, `/interviews`) с токеном сессии; другие служебные пути сервиса воронки по-прежнему недоступны через BFF.

#### Scenario: Сводка через BFF
- **WHEN** авторизованный пользователь запрашивает сводку и интервью за сутки
- **THEN** запросы уходят в сервис воронки с токеном его сессии

#### Scenario: Служебные пути закрыты
- **WHEN** через BFF запрашивают путь вида `/overview-export`
- **THEN** возвращается 404, запрос не пересылается
