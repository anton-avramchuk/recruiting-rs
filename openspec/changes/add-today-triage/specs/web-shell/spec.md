## MODIFIED Requirements

### Requirement: Навигация и оформление «Ритм»
Клиентское приложение SHALL предоставлять разделы «Сегодня», «Вакансии», «Отклики» и «Кандидаты» и называться «Ритм»; корневой маршрут открывает «Сегодня». Цвет сигнала (оранжево-красный) MUST означать только время и срочность — просроченные отклики, давно открытые вакансии, главное действие; различия между этапами выражаются плотностью начертания, а не цветом. Оформление поддерживает светлую и тёмную схемы по настройке системы и остаётся читаемым на узком экране.

#### Scenario: Разделы воронки
- **WHEN** авторизованный пользователь открывает приложение
- **THEN** в навигации есть «Сегодня», «Вакансии», «Отклики» и «Кандидаты», а разделы с реализованным содержимым не показывают заглушки

#### Scenario: Корневой маршрут
- **WHEN** авторизованный пользователь открывает `/`
- **THEN** показывается раздел «Сегодня»

#### Scenario: Цвет только для срочности
- **WHEN** отклик просрочен по SLA
- **THEN** его время на этапе выделено цветом сигнала, а непросроченные отклики и названия этапов цвета не используют
