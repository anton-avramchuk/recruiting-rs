## Why

В шапке прототипа «Ритм» рядом с поиском есть кнопки «+ Добавить» (меню: кандидат, вакансия, импорт), «Разбор» с подсказкой `T` и «?» (шпаргалка). В реализации эти действия доступны только клавишами и палитрой, мышью их не найти.

## What Changes

- Кнопка «+ Добавить» открывает меню: «Кандидат» (карточка вручную), «Вакансия» (сразу с открытой формой), «Импорт из файла» (подсказка `I`). Меню закрывается по `Esc`, клику вне меню и выбору пункта.
- Кнопка «Разбор» с сигнальной точкой и подсказкой `T` ведёт в режим разбора откликов.
- Кнопка «?» открывает шпаргалку клавиш.
- «+ Добавить» и «Разбор» скрыты для роли `viewer`; «?» видна всем.
- Адрес `/vacancies?new=1` открывает экран вакансий с развёрнутой формой создания; команда палитры «Создать вакансию» использует его.
- `AppShell` получает необязательный слот действий, чтобы admin-приложение осталось без них.
- Без новых серверных API.
