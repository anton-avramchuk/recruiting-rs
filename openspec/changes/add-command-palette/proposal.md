## Why

В прототипе «Ритм» всё частотное делается без мыши: палитра команд по Ctrl K, переходы «G + буква», шпаргалка «?». В реализации есть только клавиша T (разбор откликов). Это последняя незакрытая часть прототипа, и она делает работу рекрутера заметно быстрее.

## What Changes

- Палитра команд (Ctrl/⌘ K, кнопка поиска в шапке): единый поиск по действиям, разделам, вакансиям и людям; навигация стрелками, Enter запускает, Esc закрывает.
- Горячие клавиши оболочки: `G` затем `T`/`V`/`O`/`C`/`A` — переход по разделам; `/` — фокус в строку поиска списка кандидатов; `I` — импорт; `?` — шпаргалка; существующая `T` — разбор откликов.
- Шпаргалка клавиш (модальное окно) со списком только реализованных сочетаний.
- Действия, меняющие данные (добавить кандидата, создать вакансию, импорт, разбор), недоступны роли `viewer`.
- Без новых серверных API: люди ищутся через существующий `GET /persons?q=`, вакансии — через `GET /vacancies`, запросы идут напрямую в BFF.
- Не входит: клавиши списка и карточки (J/K, X, 1…8, E/R/S/N/M), тема, «Исследование рынка», фильтры-команды — отдельные change по мере появления самих функций.

## Capabilities

### New Capabilities
- `command-palette`: палитра команд, горячие клавиши оболочки и шпаргалка клавиш клиентского приложения.

## Impact

- `apps/web-crm`: новый модуль `palette` (компоненты, реестр команд, чистые функции фильтрации), перенос обработчика клавиши T в общий обработчик клавиатуры, кнопка поиска в шапке.
- `crates/ui-kit`: стили палитры и шпаргалки; при необходимости модальный слой.
- Тесты: юнит-тесты реестра/фильтра/разбора последовательностей, браузерный e2e `web_palette`.
