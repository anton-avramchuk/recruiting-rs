## MODIFIED Requirements

### Requirement: Список откликов
Система SHALL возвращать постраничный список откликов с общим количеством. Каждая строка содержит данные человека (имя, источник, город, ожидаемая зарплата), вакансию, этап, совпадение, время на этапе, признак просрочки и число откликов этого человека. Фильтры: вакансия, заказчик вакансии (`client_id`), этап, источник, человек и текстовый поиск `q` по имени, должности вакансии, названию заказчика, городу, навыкам и email без учёта регистра (спецсимволы поиска буквальные); фильтры комбинируются по «И». Сортировка: по времени на этапе (по умолчанию — давно без движения выше), имени, этапу, совпадению, зарплате. Размер страницы по умолчанию 50, максимум 200; некорректные параметры, в том числе `client_id`, дают 400.

#### Scenario: Фильтр и поиск
- **WHEN** запрошены отклики на этапе «Скрининг» с поиском «москва»
- **THEN** возвращаются только такие отклики, где в данных человека или названии вакансии есть «москва»

#### Scenario: Вся доска вакансии
- **WHEN** запрошены отклики одной вакансии с максимальным размером страницы
- **THEN** возвращаются все отклики этой вакансии (до 200), по которым можно построить доску

#### Scenario: Сортировка по имени
- **WHEN** запрошена сортировка по имени
- **THEN** строки упорядочены по имени человека независимо от регистра

#### Scenario: Отклики заказчика
- **WHEN** запрошены отклики с `client_id` заказчика Acme
- **THEN** возвращаются только отклики на вакансии Acme, общее количество считается по ним же

#### Scenario: Поиск по названию заказчика
- **WHEN** запрошен поиск `q=acme`
- **THEN** в выдаче есть отклики на вакансии заказчика «Acme Corp», даже если слова «acme» нет в данных человека

#### Scenario: Заказчик в комбинации с другими фильтрами
- **WHEN** заданы `client_id` и этап «Скрининг»
- **THEN** возвращаются только отклики этого заказчика на этом этапе

#### Scenario: Чужой или неверный заказчик
- **WHEN** `client_id` не похож на идентификатор
- **THEN** возвращается 400; заказчик другой организации даёт пустую выдачу
