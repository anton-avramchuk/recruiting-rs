## Why

В `identity` уже есть API пользователей организации (`GET/POST /users`, `PATCH /users/{id}`), но в CRM нет экрана: чтобы завести рекрутера или сменить роль, нужен ручной вызов API. Кроме того, в API нет защиты от потери организации (последний владелец может понизить себя), нет сброса пароля владельцем, а блокировка и смена роли не отзывают действующие сессии.

## What Changes

- **Экран «Безопасность»** в CRM (виден и доступен владельцу, `owner`): список пользователей организации с ролью и статусом, создание пользователя (email, имя, роль, начальный пароль), смена роли, блокировка и разблокировка, сброс пароля, правка имени.
- **Защита владельца**: нельзя оставить организацию без активного владельца (понизить или заблокировать последнего активного владельца); блокировка себя по-прежнему запрещена.
- **Сброс пароля**: `owner` задаёт новый пароль пользователю (`password` в `PATCH /users/{id}`); все refresh-токены пользователя отзываются.
- **Отзыв сессий**: блокировка, смена ролей и сброс пароля отзывают refresh-токены пользователя, поэтому новая пара токенов не выдаётся; действующий access-токен живёт до истечения своего короткого срока.
- Для остальных ролей экран и пункт меню не показываются; прямой переход даёт понятное сообщение об отсутствии прав.
- Без новых сервисов и миграций; приглашения по почте не входят (пароль задаёт владелец).

## Capabilities

### New Capabilities
- `security`: экран «Безопасность» в CRM — список, создание, роли, блокировка, сброс пароля.

### Modified Capabilities
- `identity-auth`: инвариант «всегда есть активный владелец», сброс пароля владельцем, отзыв сессий при блокировке, смене ролей и сбросе пароля.

## Impact

- `identity`: сервис пользователей (инвариант владельца, пароль в `UpdateUserRequest`, отзыв токенов), тесты `users.rs`.
- `bff-crm`: путь `/users` уже в allowlist; изменений нет (проверить, что CSRF и метод PATCH проходят).
- `apps/web-crm`: серверные функции пользователей, страница `/security`, пункт меню для `owner`, команда в палитре.
- Тесты: API identity, браузерный e2e «Безопасность».
