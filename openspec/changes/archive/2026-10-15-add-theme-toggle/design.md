## Context

Токены цвета заданы на `:root`, тёмный вариант — под `@media (prefers-color-scheme: dark)`; `color-scheme: light dark`. `UiStyles` (ui-kit) вставляет CSS в тело документа в начале `App`; оба приложения используют общий `AppShell` из ui-kit.

## Goals / Non-Goals

**Goals:** ручное переключение, запоминание, без вспышки, оба приложения, палитра.
**Non-Goals:** третье состояние «как в системе» в интерфейсе (сброс выбора), синхронизация темы между устройствами (серверное хранение).

## Decisions

- **CSS**: тёмные токены выносятся в один блок, применяемый в двух случаях: `:root[data-theme="dark"]` и `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) }`. Свет по умолчанию. Плюс `color-scheme` по `data-theme`, чтобы системные элементы (поля, прокрутка) совпадали.
- **Ранняя установка**: маленький inline-скрипт в `UiStyles` (в самом начале тела, до разметки) читает `localStorage["theme"]` в `try/catch` и ставит `document.documentElement.dataset.theme`, если значение `light|dark`. Скрипт синхронный → кадра с неверной темой нет; гидратация не затрагивает корневой атрибут.
- **Чистая логика**: `fn next_theme(stored: Option<&str>, system_dark: bool) -> &'static str` — действующая тема = сохранённая или по системе, результат противоположный. Юнит-тесты в ui-kit.
- **Переключение в браузере**: функция `toggle_theme()` (hydrate): читает `data-theme`, `matchMedia("(prefers-color-scheme: dark)")`, вызывает `next_theme`, пишет в `dataset` и в `localStorage` (ошибки хранилища игнорируются). Нужны features `web-sys`: `MediaQueryList`, `Storage`, `Window`.
- **Кнопка** в `AppShell` (общая для приложений) после пользователя, до «Выйти»: `data-testid="theme-button"`, `aria-label="Переключить тему"`; состояние — `aria-pressed` = «тёмная»; значок ◐ (текстовый, без новых ресурсов).
- **Палитра**: команда `Target::ToggleTheme` вызывает ту же функцию.
- **Зависимость от темы системы «на лету»**: достигается самим CSS-медиазапросом, пока нет явного `data-theme`.

## Risks / Trade-offs

- Состояние `aria-pressed` считывается из DOM при клике, а не реактивно из сигнала: после смены системной темы без клика оно может отстать до следующего нажатия. Приемлемо.
- Скрипт в теле документа — единственный inline-скрипт; CSP в проекте не настроена.
