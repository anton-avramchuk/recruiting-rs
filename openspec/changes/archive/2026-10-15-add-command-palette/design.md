## Context

Оболочка (`AppShell` из ui-kit) уже есть; клавиша T реализована прямо в `Protected` (`apps/web-crm/src/lib.rs`) с проверками `typing_in_a_field` и `panel_is_open`. Клиентские вызовы BFF изоморфны (`ui_kit::api::call`), поиск людей — `GET /persons?q=` (`candidates::server::search_persons`), вакансии — `GET /vacancies`.

## Goals / Non-Goals

**Goals:** палитра, переходы `G + буква`, `/`, `I`, `?`, шпаргалка; единый обработчик клавиатуры; права `viewer`.
**Non-Goals:** клавиши списка/карточки, тема, новые API, хранение истории команд.

## Decisions

- **Модуль `apps/web-crm/src/palette/`**: `commands.rs` (реестр и чистая фильтрация/группировка, без Leptos — тестируется юнитами), `keys.rs` (чистый автомат последовательностей `G+x` с отсчётом времени от внешних меток, список шпаргалки), `view.rs` (компоненты палитры и шпаргалки). Логика отдельно от DOM — тесты сначала на чистых функциях.
- **Один обработчик `keydown`** в `Protected` заменяет текущий для T: сначала Ctrl/⌘ K, затем режим палитры/шпаргалки/панели, затем поле ввода, затем одиночные клавиши. Состояние (`palette_open`, `cheat_open`) — сигналы в контексте, чтобы кнопка в шапке и пункт меню открывали то же.
- **Поиск на сервере с отсрочкой 200 мс**: `Resource` от «устоявшегося» запроса; людей — `search_persons` с лимитом 7, вакансии — единожды загружаем список при первом открытии и фильтруем на клиенте (их немного). Устаревшие ответы отбрасываются сравнением запроса. Ошибка → группа не показывается.
- **Кнопка поиска в шапке**: `AppShell` получает необязательный слот/колбэк `on_search`; подсказка «Ctrl K» рядом.
- **Права**: реестр команд принимает `can_write`; команды записи не попадают в список для viewer, обработчик клавиш проверяет то же правило.
- **Действия «Добавить кандидата»/«Создать вакансию»**: переходят на `/candidates/new` и `/vacancies` с открытием формы (если у экрана вакансий нет адресуемой формы — просто переход к экрану; уточнить при реализации).
- **Доступность**: палитра — `role="dialog"` + `aria-modal`, список — `role="listbox"`, выбранный пункт `aria-selected`; фокус возвращается на прежний элемент при закрытии.

## Risks / Trade-offs

- Конфликт с браузером: Ctrl K в некоторых браузерах фокусирует адресную строку → `preventDefault`.
- Гонки ответов поиска → сравнение с актуальным запросом.
- Раскладка: клавиши сравниваются по `key` в нижнем регистре, поэтому в русской раскладке `G/T/…` не сработают; сочетания по `code` (`KeyG`…) делают их независимыми от раскладки — использовать `code` для букв, `key` для `?` и `/`.
