## ADDED Requirements

### Requirement: Пакетный импорт кандидатов
Система SHALL принимать пакет строк (до 500 за запрос) и для каждой строки создавать кандидата либо объединять строку с существующим. Каждая строка проверяется теми же правилами, что и обычное создание (ФИО, контакты, зарплата, навыки, места работы, образование); строка с ошибкой отклоняется с указанием поля, остальные строки пакета обрабатываются. «Тот же человек» ищется внутри организации по email, затем по телефону, затем по ФИО (как при создании). У найденного человека заполняются только пустые поля (телефон, email, Telegram, WhatsApp, город, источник, ожидания, краткое описание); существующие значения не изменяются, навыки дополняются недостающими, места работы и образование добавляются, только если у человека их ещё нет. Строки одного пакета, совпадающие между собой, объединяются так же. Ответ содержит для каждой строки (по номеру в пакете) результат «создан», «объединён» или «отклонён» с идентификатором кандидата либо причиной. Пакет выполняется в одной транзакции организации.

#### Scenario: Новые люди
- **WHEN** отправлены две строки с разными людьми
- **THEN** созданы два кандидата, ответ содержит для каждой строки результат «создан» и идентификатор

#### Scenario: Человек уже есть
- **WHEN** строка совпадает по email с существующим кандидатом, у которого нет города
- **THEN** кандидат не дублируется, ему добавлен город из строки, остальные поля не изменены, результат «объединён»

#### Scenario: Существующие значения сохраняются
- **WHEN** у найденного человека есть телефон, а в строке другой телефон
- **THEN** телефон человека остаётся прежним

#### Scenario: Частичный успех
- **WHEN** в пакете строка без имени, строка с некорректным email и две корректные
- **THEN** две корректные созданы, две остальные отклонены с полем и причиной, пакет принят целиком (200)

#### Scenario: Дубли внутри пакета
- **WHEN** две строки пакета содержат один и тот же email
- **THEN** создан один кандидат, вторая строка объединена с ним

#### Scenario: Слишком большой пакет
- **WHEN** отправлено больше 500 строк
- **THEN** возвращается 400, ничего не создаётся

#### Scenario: Права и изоляция
- **WHEN** пакет отправляет `viewer` или пользователь другой организации ищет совпадения
- **THEN** `viewer` получает 403, а поиск совпадений видит только кандидатов своей организации
