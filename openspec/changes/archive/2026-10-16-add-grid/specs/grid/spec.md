## ADDED Requirements

### Requirement: Единый формат запроса грида
Система SHALL принимать запросы списков в одном формате: номер страницы, размер страницы, сортировка по нескольким полям и рекурсивный фильтр с группами `and`/`or`. Поддерживаются операторы `eq`, `neq`, `contains`, `startswith`, `endswith`, `gt`, `gte`, `lt`, `lte`, `isnull`, `isnotnull`, `isempty`, `isnotempty`. По HTTP запрос передаётся параметрами `page`, `page_size`, `sort` (`поле:asc,поле:desc`) и `filter` (JSON). Ответ содержит строки страницы, общее число записей, номер страницы и размер страницы. Имена полей сопоставляются без учёта регистра и знаков подчёркивания.

#### Scenario: Страница и общее число
- **WHEN** запрошена вторая страница по 10 записей при 25 подходящих записях
- **THEN** возвращаются записи 11–20, `total` равно 25

#### Scenario: Сортировка по нескольким полям
- **WHEN** запрошена сортировка `status:asc,email:desc`
- **THEN** записи упорядочены по статусу, внутри одного статуса по email по убыванию

#### Scenario: Группы условий
- **WHEN** фильтр — группа `or` из двух условий внутри группы `and` с третьим условием
- **THEN** возвращаются записи, удовлетворяющие третьему условию и хотя бы одному из первых двух

#### Scenario: Стабильный порядок
- **WHEN** сортировка не задана или поля сортировки совпадают у нескольких записей
- **THEN** порядок записей между запросами одинаков, страницы не пересекаются

### Requirement: Безопасность запросов грида
Сервер SHALL принимать в запросе грида только поля из заданной для списка схемы (белый список с признаками «сортируется» и «фильтруется»). Значения фильтра MUST передаваться в SQL только параметрами и приводиться к типу столбца. Запрос вне схемы или лимитов отклоняется с 400 и указанием проблемного параметра. Лимиты: размер страницы по умолчанию 20, не больше 100; глубина фильтра не больше 4; условий не больше 32; ключей сортировки не больше 3; значение условия не длиннее 200 символов; параметр `filter` не длиннее 4 КБ. Изоляция организаций сохраняется: запрос выполняется в контексте тенанта.

#### Scenario: Неизвестное поле
- **WHEN** фильтр или сортировка ссылается на поле, которого нет в схеме
- **THEN** возвращается 400, в ответе указан параметр

#### Scenario: Запрещённая операция
- **WHEN** запрошена сортировка или фильтр по полю, у которого это отключено
- **THEN** возвращается 400

#### Scenario: Оператор не подходит типу
- **WHEN** оператор `contains` применён к числовому полю или значение не приводится к типу поля
- **THEN** возвращается 400

#### Scenario: Спецсимволы и инъекции
- **WHEN** значение фильтра содержит `%`, `_`, `'` или текст SQL
- **THEN** оно ищется буквально, запрос не меняется, данные не раскрываются

#### Scenario: Превышение лимитов
- **WHEN** размер страницы больше предела, фильтр глубже допустимого или условий больше допустимого
- **THEN** возвращается 400

#### Scenario: Другая организация
- **WHEN** пользователь организации A запрашивает грид
- **THEN** записи организации B не попадают ни в строки, ни в `total`

### Requirement: Компонент таблицы с серверными данными
Интерфейс SHALL предоставлять общий компонент `Grid`: столбцы с сортировкой по клику на заголовок, фильтры столбцов (текст или выбор из списка), общий поиск по помеченным столбцам, пейджер с подписью «с–по из всего» и выбором размера страницы, а также состояния загрузки, пустоты и ошибки. Данные запрашиваются с сервера на каждое изменение страницы, сортировки, фильтра или поиска; во время загрузки прежние строки остаются на экране. Текстовые фильтры и поиск применяются после короткой паузы в наборе. Строка может быть ссылкой. Таблица доступна для скринридеров (заголовки столбцов, направление сортировки).

#### Scenario: Сортировка по заголовку
- **WHEN** пользователь нажимает заголовок сортируемого столбца
- **THEN** список сортируется по возрастанию, повторное нажатие — по убыванию, третье — сортировка снимается

#### Scenario: Фильтр столбца
- **WHEN** пользователь вводит текст в фильтр столбца или выбирает значение из списка
- **THEN** показаны только подходящие записи, страница сброшена на первую, подпись пейджера пересчитана

#### Scenario: Общий поиск
- **WHEN** пользователь вводит текст в поиск
- **THEN** показаны записи, у которых хотя бы в одном из помеченных столбцов есть вхождение

#### Scenario: Пейджер
- **WHEN** записей больше размера страницы
- **THEN** доступны «Назад» и «Вперёд», подпись показывает диапазон и общее число, выбор размера страницы меняет число строк

#### Scenario: Пусто и ошибка
- **WHEN** по фильтрам ничего не найдено, либо список не удалось загрузить
- **THEN** показаны пустое состояние с кнопкой сброса фильтров либо сообщение об ошибке, без падения страницы

### Requirement: Состояние грида в адресе
Компонент `Grid` SHALL хранить страницу, размер страницы, сортировку, поиск и фильтры столбцов в параметрах адресной строки, не добавляя запись в историю при каждом нажатии клавиши. Открытие страницы по такому адресу восстанавливает то же представление. Смена фильтра или поиска возвращает страницу на первую.

#### Scenario: Ссылка на представление
- **WHEN** пользователь открывает адрес с `page=2&sort=email:desc&f.status=blocked`
- **THEN** показана вторая страница отфильтрованного и отсортированного списка, элементы управления отражают эти значения

#### Scenario: Обновление страницы
- **WHEN** пользователь меняет сортировку и обновляет страницу браузера
- **THEN** сортировка сохраняется

### Requirement: Список пользователей на гриде
Экран «Безопасность» SHALL показывать пользователей организации в `Grid` со столбцами «Пользователь» (имя и email, поиск), «Роль» (фильтр выбором), «Статус» (фильтр выбором), «Создан» (сортировка). Строка ведёт на страницу пользователя.

#### Scenario: Фильтр по статусу
- **WHEN** владелец выбирает статус «Заблокирован»
- **THEN** в списке только заблокированные пользователи

#### Scenario: Поиск пользователя
- **WHEN** владелец вводит часть email или имени
- **THEN** в списке только подходящие пользователи

#### Scenario: Большой список
- **WHEN** в организации больше 20 пользователей
- **THEN** список разбит на страницы, подпись пейджера показывает общее число
