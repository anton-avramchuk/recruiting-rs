## ADDED Requirements

### Requirement: CORS для обращений браузера
BFF SHALL допускать запросы браузера с других источников (origin) только из явно настроенного списка. Для запроса с источником из списка ответ содержит `Access-Control-Allow-Origin` с этим источником (не `*`), `Access-Control-Allow-Credentials: true` и `Vary: Origin`. Предзапрос (`OPTIONS`) с разрешённым источником получает ответ без проверки сессии и CSRF-токена и разрешает методы `GET`, `POST`, `PUT`, `PATCH`, `DELETE` и заголовки `content-type`, `x-csrf-token`. Для источника вне списка CORS-заголовки не добавляются. Если список пуст, поведение остаётся прежним (CORS выключен). Значение `*` в настройке MUST отклоняться при запуске. Проверка CSRF-токена для изменяющих запросов MUST оставаться обязательной и для запросов с других источников.

#### Scenario: Разрешённый источник
- **WHEN** браузер с источника из списка запрашивает `/bff/session` с cookie
- **THEN** ответ содержит этот источник в `Access-Control-Allow-Origin` и `Access-Control-Allow-Credentials: true`

#### Scenario: Предзапрос без сессии
- **WHEN** приходит `OPTIONS /api/persons` с разрешённым источником и без cookie
- **THEN** возвращается успешный ответ с разрешёнными методами и заголовками, запрос в бэкенд не уходит

#### Scenario: Чужой источник
- **WHEN** запрос приходит с источника вне списка
- **THEN** CORS-заголовков в ответе нет, предзапрос не разрешает ничего

#### Scenario: CSRF остаётся обязательным
- **WHEN** разрешённый источник отправляет изменяющий запрос без `x-csrf-token`
- **THEN** возвращается 403, запрос в бэкенд не уходит

#### Scenario: Подстановка запрещена
- **WHEN** в настройке источников указано `*`
- **THEN** сервис не запускается с понятной ошибкой конфигурации

#### Scenario: CORS выключен по умолчанию
- **WHEN** список источников не задан
- **THEN** ответы не содержат CORS-заголовков
