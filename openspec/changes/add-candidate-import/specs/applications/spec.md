## ADDED Requirements

### Requirement: Пакетное создание откликов
Система SHALL создавать отклики на одну вакансию для набора кандидатов одним запросом (до 500 идентификаторов): для каждого существующего кандидата организации, у которого ещё нет отклика на эту вакансию, создаётся отклик на этапе «Новый» (либо на указанном этапе), в историю которого записывается событие с источником («Импортирован из файла …», если источник указан, иначе «Получен отклик»). Ответ содержит число созданных откликов, число пропущенных из-за уже существующего отклика и число не найденных кандидатов. Неизвестная вакансия MUST давать 404, больше 500 идентификаторов — 400.

#### Scenario: Отклики на вакансию
- **WHEN** запрошено создание откликов на вакансию для трёх кандидатов, у одного из которых отклик уже есть
- **THEN** созданы два отклика, один пропущен, у новых откликов в истории «Импортирован из файла …»

#### Scenario: Неизвестные кандидаты
- **WHEN** среди идентификаторов есть кандидат, которого нет в организации
- **THEN** он учтён в числе не найденных, остальные обработаны

#### Scenario: Неизвестная вакансия
- **WHEN** указана вакансия, которой нет в организации
- **THEN** возвращается 404, отклики не создаются

#### Scenario: Права
- **WHEN** запрос отправляет `viewer`
- **THEN** возвращается 403
